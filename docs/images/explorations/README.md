# Explorations

Dead ends and superseded concepts, kept as a record of what was considered.
**None of these are the shipped design** — see the repo README for that.

## Overtime — current candidate

`overtime-NN.svg` is the proposed handling for blocks longer than the 60 minute
dial face, generated by `docs/render_overtime_concept.py --style shipped`. It is
**additive to the shipped dial**: disc, tick dots and hand are unchanged, and a
thin ring is dropped into the empty band between disc edge and dots.

Walk the sequence to assess it — 90, 75, 61, 60, 59, 45, 30, 15, 0:

| State | What it shows |
|---|---|
| 90 / 75 / 61 | Disc **full**, ring draining the overflow hour |
| 60 | Hand at twelve, disc full, ring gone |
| 59 / 45 / 30 / 15 | Ring absent entirely — **identical to today's screen** |
| 0 | Empty disc, hand at twelve. The quiet state |

The ring is the high digit and the disc the low digit, like an odometer, so
nothing jumps at the hour. The hand is one fixed length throughout: the ring
fraction above the hour and the disc fraction below it are both
`(remaining mod 60) / 60`, so it sweeps continuously past twelve — 61 min sits
at 6°, 60 at 0°, 59 at 354°.

`overtime-armed-*.svg` show the dimmed armed preview, ring included.

## Rejected

- `overtime-spiral-*.svg` — one track winding inward, a turn per hour. Reads
  well, but there is no fixed scale to read minutes against, the tick ring
  cannot coexist with it, and it needs an `lv_canvas` redraw rather than a
  couple of objects.
- `spiral-*.svg`, `dial-90-*.svg` — earlier overflow attempts where the disc
  showed `remaining mod 60`. All rejected for the same reason: crossing the hour
  flipped the disc from a sliver to nearly full.
- `operator-wedge-*.svg`, `operator-session-concept*.svg` — layout studies from
  before the dial was settled.
